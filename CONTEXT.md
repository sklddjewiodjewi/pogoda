# Погода — контекст проекта

Одностраничный прогноз погоды: один файл `index.html` без сборки и без сервера. Данные берутся прямо из браузера с Open-Meteo (бесплатно, без ключа, CORS открыт). Страница публикуется через GitHub Pages.

Автор требований — Михаил. Ниже собраны требования и решения, принятые по ходу разработки.

## Принципы

- **Не добавлять функции, о которых не просили.** Любая новая возможность появляется только по явной просьбе.
- Замечания собираются списком. Код меняется только по команде «генери».
- Интерфейс на русском, единицы: °C, м/с, мм.

## Источники данных (Open-Meteo)

| Период | Источник | Почему |
|---|---|---|
| Прошлое, последние 92 дня | Forecast API, `past_days=92` (best match) | Приходит в одном запросе с прогнозом |
| Прошлое глубже (с 2022 г.) | Historical Forecast API, порциями по 60 дней | Подгружается, когда лента долистана до левого края |
| Сегодня, завтра, послезавтра | ECMWF IFS HRES 9 км (`ecmwf_ifs`, запасной `ecmwf_ifs025`) | Самая точная модель на короткий срок |
| С 4-го по 15-й день | Ансамбль ECMWF, среднее 51 прогноза | На дальних сроках среднее ансамбля точнее одного прогноза |
| Всё, что не пришло из моделей выше | Forecast API, best match, 16 дней | Запасной вариант; из него же УФ-индекс и день/ночь |

- **Свой архив погоды не храним** — у поставщика он есть. В `localStorage` лежат только выбранное место и список 10 последних мест.
- Для ансамбля значок погоды выводится из облачности и осадков (кода погоды там нет). Ощущаемой температуры в ансамбле нет — для дальних дней показывается только основная.
- Поиск городов — Open-Meteo Geocoding API, язык `ru`.

## Раскладка

- **Шапка:** название места, в той же строке регион и время обновления; справа поле поиска и кнопка «Обновить».
- Заголовок вкладки браузера: «Погода <место>».
- **Поиск:** при клике на пустое поле — выпадающий список 10 последних мест (без текущего), при вводе — подсказки городов.
- **Слева вертикальные вкладки:** Вчера, Сейчас, Сегодня, Завтра, 3 дня, 2 недели. Синим выделена только активная. Список поджат; если не помещается по высоте — прокручивается только он.
- **Справа от вкладок:** карточка выбранного дня, под ней лента дней.
  - Карточка соответствует выбранному дню. Для «Сегодня/Сейчас» — текущая погода (температура, влажность, ощущается, ветер, УФ). Для других дней — сводка: макс/мин, осадки, ветер, УФ.
  - Время «Сейчас, 05:30» не показывается.
- **Лента дней:** слева архив, справа прогноз, между ними черта.
  - При открытии сегодняшний день стоит первым у левого края.
  - Полосы прокрутки нет. Лента двигается перетаскиванием мышью прямо за карточки, колесом мыши, пальцем на телефоне.
  - Кнопки «← Архив», «● К сегодня», «Прогноз →» с лёгким цветным фоном. «Архив/Прогноз» сдвигают ровно на один день, край ленты встаёт по границе карточки.
  - Клик по обрезанной краем карточке подкручивает ленту, чтобы она была видна целиком.
  - Вкладки ленту и страницу не прокручивают.
  - Карточка дня низкая, в две строки: «пн, 2 ноя» / значок, «+29° / +24°», кружок УФ сбоку. Цветная точка — источник прогноза.
- **Таблица дня** (по образцу сайта из исходного скриншота): заголовок по центру, колонки каждые 3 часа (1:00…22:00), бледные вертикальные разделители между колонками. Слева вместо текстовых подписей — иконки строк, расшифровка в подсказке.
  - Значок погоды.
  - Полоса температуры с цветом по шкале холод/жара, рядом мелко — ощущается («+27 / +29»).
  - Ветер одной строкой без рамок: «3 / 5 ↑Ю» — скорость / порывы, стрелка и направление (откуда дует).
  - Осадки за 3 часа.
  - УФ-индекс.
- **2 недели:** таблица по дням на 16 дней (макс, мин, осадки, порывы, УФ, источник); клик по строке раскрывает день.
- Подвала нет.

## УФ-индекс

- Кружок с числом, без надписи «УФ»; что это — в подсказке («УФ-индекс 8 — очень высокий»).
- Приглушённые пастельные цвета по шкале ВОЗ (0–2, 3–5, 6–7, 8–10, 11+), чтобы не выпячивались.
- Если максимум УФ за день низкий (0–2), УФ для этого дня не показывается нигде.

## Подсказки

У каждого элемента, который сам себя не объясняет, есть подсказка: значки погоды (описание по коду WMO), карточки дней, ячейки таблицы, иконки строк, кнопки, вкладки, поиск. На сенсорных экранах подсказка всплывает по касанию.

## Размеры

- Боковые поля около 1 см, нижнее около 1 мм, ширина не ограничена.
- Вертикальные отступы минимальные.
- **Резиновость по вертикали:** страница занимает ровно высоту окна без прокрутки (от 13″). Верхний блок и таблица дня масштабируются по высоте окна; в таблице больше всего растут значки и полоса температуры.
- «3 дня»: три таблицы делят высоту; если не помещаются — прокручивается только область таблиц.

## Мобильная версия (до 640 px)

- Вкладки — сетка 3×2 сверху.
- Таблица дня без горизонтального листания: 4 колонки по 6 часов (4:00, 10:00, 16:00, 22:00); осадки суммируются за 6 часов, порывы — максимум за 6 часов.
- В «2 неделях» скрыты колонки «Порывы» и «Источник».
- Страница прокручивается обычным образом.

Светлая и тёмная — по настройке системы.
